# Hoy

App personal diaria de Sergio (uso propio): ánimo, recuperación, entrenamiento (semana 1 de retorno), comida planificada el día anterior, estudio de Cálculo y lectura espiritual con audio.

## Abrirla en el teléfono
1. Abre https://sergioega07-cpu.github.io/hoy/ en Safari (iPhone) o Chrome (Android).
2. Safari → Compartir → **Añadir a pantalla de inicio** (Chrome: menú ⋮ → Instalar app).

## Datos
Todo vive **solo en ese navegador** (localStorage; audios en IndexedDB). No hay cuenta ni servidor. Si borras los datos del navegador, se pierden.

## Fuentes
- Macros del catálogo: USDA FoodData Central, SR Legacy, valores por 100 g (FDC IDs en `foods.json`). Porciones aproximadas. Puedes crear alimentos propios con tus valores.
- Versículo: Reina-Valera 1909 (dominio público).
- El ejercicio de Cálculo es un ejemplo, no tu capítulo actual.
